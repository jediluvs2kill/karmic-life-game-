# Public civilization design

Each invention has a recognizable 3D representation, stable project identity, and connected terrain address. The public release contains only the minimal invention catalogue; it does not include private conversation records.

The game separates append-only events from their dated rendering. Shared ideas receive a place; recorded work adds equipment and architectural upgrades. Source attribution and truth states remain visible. Agent animation is not evidence of reasoning; actual optional local-model outputs are recorded separately.

Architecture references: [AI Town](https://github.com/a16z-infra/ai-town) for shared-world state, [Generative Agents](https://github.com/joonspk-research/generative_agents) for memory boundaries, and [Habitica](https://github.com/HabitRPG/habitica) for readable progression. This repository implements its own Three.js world rather than incorporating those codebases.
